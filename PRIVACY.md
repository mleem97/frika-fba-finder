### Local processing only

FBA Finder – Smart Shopping Filter processes marketplace search-result content only inside the user's browser. It does not transmit search queries, browsing history, product data, prices, identifiers, usage data, or personal data to Meyer Media or any third party.

The extension contains:

- no analytics or telemetry;
- no advertising or affiliate tracking;
- no remote code;
- no external API requests;
- no account or login system;
- no cookies created by the extension.

### Browser storage

The extension stores only user-selected settings and local filter counters through the browser extension storage API:

- `storage.sync`: filter settings and per-marketplace preferences. The browser vendor may synchronize this data when browser sync is enabled. Meyer Media cannot access it.
- `storage.local`: the current page's filter counters and whether the on-page indicator was dismissed. This data remains on the device.

Search-result text, titles, product prices, and shipping prices are inspected in memory and are not written to extension storage.

### Site access

Content scripts run only on the marketplace domains declared in the extension manifest: Amazon, AliExpress, Alibaba, Temu, SHEIN, DHgate, Banggood, and eBay. Access is used solely to identify, compare, hide, mark, dim, or reorder result cards according to the user's settings.

The only extension API permission is `storage`. Opening the local “What’s new” and settings pages does not transmit data.

### Data sharing and retention

Meyer Media receives no data from the extension and therefore does not share or retain extension user data. Uninstalling the extension removes its locally stored data according to the browser's extension data lifecycle.

### Rights and contact

Where the GDPR applies, data subjects have the rights provided by Articles 15–21 GDPR. Because Meyer Media does not receive or store extension user data, there is normally no user dataset that Meyer Media can access, export, correct, or delete.

### Ausschließlich lokale Verarbeitung

FBA Finder – Smart Shopping Filter verarbeitet Inhalte von Marktplatz-Suchergebnissen ausschließlich im Browser des Nutzers. Suchbegriffe, Browserverlauf, Produktdaten, Preise, Kennungen, Nutzungsdaten oder personenbezogene Daten werden weder an Meyer Media noch an Dritte übertragen.

Die Erweiterung enthält keine Analyse, Telemetrie, Werbung, Affiliate-Verfolgung, externen APIs, Remote-Code, Nutzerkonten oder eigene Cookies.

### Browser-Speicher

- `storage.sync` speichert Filter- und Marktplatz-Einstellungen. Bei aktivierter Browser-Synchronisierung kann der Browseranbieter diese Einstellungen synchronisieren; Meyer Media hat darauf keinen Zugriff.
- `storage.local` speichert ausschließlich aktuelle Filterzähler und die Einstellung, ob der Seitenhinweis ausgeblendet wurde.

Texte, Produkttitel sowie Artikel- und Versandpreise werden nur im Arbeitsspeicher geprüft und nicht dauerhaft gespeichert.

### Webseitenzugriff

Content Scripts laufen ausschließlich auf den im Manifest genannten Domains von Amazon, AliExpress, Alibaba, Temu, SHEIN, DHgate, Banggood und eBay. Der Zugriff dient nur dazu, Ergebnis-Karten nach den gewählten Einstellungen zu erkennen, zu vergleichen, auszublenden, abzudunkeln, zu markieren oder zu sortieren.

Die einzige API-Berechtigung der Erweiterung ist `storage`.

### Weitergabe, Speicherdauer und Rechte

Meyer Media erhält keine Daten aus der Erweiterung und kann daher keine Erweiterungs-Nutzerdaten weitergeben oder speichern. Eine Deinstallation entfernt die lokalen Erweiterungsdaten entsprechend dem Datenlebenszyklus des Browsers.

Soweit die DSGVO anwendbar ist, bestehen die Rechte aus Art. 15–21 DSGVO. Da Meyer Media keine Nutzerdaten der Erweiterung erhält, existiert regelmäßig kein personenbezogener Datensatz, den Meyer Media auslesen, berichtigen, exportieren oder löschen könnte.
