- ❌ Does NOT require user accounts or login

### Data Stored Locally

The extension stores only user preferences locally in your browser using Chrome's built-in storage API (`chrome.storage.sync`):

| Setting | Purpose |
|---------|---------|
| `enabled` | Whether the filter is active |
| `hideSponsored` | Preference for hiding sponsored products |
| `onlyPrime` | Preference for showing only Prime products |
| `viewMode` | How non-FBA products are displayed (hide/dim/border) |
| `strictPrime` | Strict Prime filtering preference |

This data:
- ✅ Is stored only in your browser
- ✅ Syncs across your Chrome browsers (if signed into Chrome)
- ✅ Can be deleted at any time by removing the extension
- ✅ Is never transmitted to external servers

## Permissions Explained

The extension requires certain permissions to function:

| Permission | Why It's Needed |
|------------|-----------------|
| `storage` | To save your filter preferences locally |
| `activeTab` | To apply filters on the current Amazon page |
| Host permissions (Amazon domains) | To run the filter on Amazon websites |

These permissions are the minimum required for the extension to work.
